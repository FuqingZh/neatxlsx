# neatxlsx 0.2.0 M1 release notes (draft)

Status: implementation complete locally; not published

The M1 report-trust implementation keeps the public Python names and preserves
all existing `Workbook.write_sheet()` calls while correcting cell semantics
and adding two keyword-only format controls:

- `header_row_formats` assigns a `Format` patch to each custom header row, with
  `None` inheriting the workbook header format;
- `column_formats` maps one column name or zero-based index to a body-cell
  `Format` patch, using precedence default role, inferred dtype role, workbook
  role format, then column rule;
- both controls are validated before native backend entry and propagate across
  every physical split worksheet;

- booleans are written as native Excel boolean cells;
- ordinary integers and decimals remain numeric, while values beyond Excel's
  safe precision are exact literal text with one `[precision-as-text]` warning
  per affected logical column;
- dates, naive datetimes, times, and safe durations use inferred Excel number
  formats, with exact text fallbacks and `[temporal-as-text]` warnings;
- categorical and Enum columns are lazily normalized to labels;
- unsupported nested or opaque dtypes fail schema preflight without poisoning
  an open workbook;
- `Format` validates domains and normalizes RGB colors; and
- the private Arrow bridge is paired at ABI/contract v4.

Validation evidence for the local implementation:

```text
CARGO_BUILD_JOBS=1 pdm run check
```

The command passed the Rust, Python, package-build, and distribution checks on
2026-08-24. Publication, CI matrix confirmation, the explicit real-row-limit
format gate, and the final Excel/LibreOffice visual review are separate release
gates and require explicit release authorization.
