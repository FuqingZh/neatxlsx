## Accepted release tradeoff — 2026-09-08

After reviewing the measured costs, the user explicitly accepted them and
authorized continuing toward release. This decision covers both the unmet
original single-pass performance target and the display-estimator budgets.
The fresh `none` median increase is 1.98%; retained full-scan `body/all` medians
are +7.31%/+4.83% against the pre-estimator single-pass baseline. These are
workload-specific measurements, not universal overhead bounds.

Performance verdicts remain failed/incomplete under their original rules.
No threshold, analyzer, sample, or test expectation is changed. For release
0.2.1, those performance results are an accepted product tradeoff rather than
a blocking prerequisite. No general end-to-end speedup is claimed.

Commit `30e02a2` passed Python 3.11/3.13/3.14 and quality CI in run
`34186808397`. The final versioned commit requires its own checks.
